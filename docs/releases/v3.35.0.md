# v3.35.0 — 表格原生预览与附件路径句柄、TUI 全高视口

> 日期：2026-10-21
> 上一版本：v3.34.1（稳定通道）

## 本版说明

本版主轴是**文件与图片的真实可用性**：桌面端打开 Excel 表格不再是乱码（SheetJS 原生渲染），发文档给 agent 时原文随消息落盘并带路径句柄（agent 不再全盘搜索），图片进模型历史前统一按字节归一格式（一张 bmp/坏图不再把会话每轮请求毒化成 400）。TUI 侧收编社区贡献的 classic 全高视口（PR #528），指令摘要钉在窗口顶部、窗口缩放后输入区保持贴底。

## 内容清单

- **桌面端表格原生预览（主打）**：
  - 文件列表 / 会话附件直接预览 xlsx/xls/ods：SheetJS 纯前端解析，多工作表标签页、A/B/C 列字母与行号、500 行 × 50 列截断提示，不依赖 LibreOffice。
  - 演示文稿（pptx/ppt/odp）仍走 LibreOffice 转 PDF；缺装时不再只有一句提示——按平台给一行可复制的安装命令（brew/winget/apt）+ 官网下载入口，装完点「重试」即出预览。
  - 「打开方式」菜单对表格提供应用内预览项（此前只能跳系统应用）。
- **文档附件路径句柄**：
  - 发送 xlsx/docx 等文档时，原文按内容寻址落盘（sha256 幂等、原子发布、只读副本）并随消息注入句柄——`Saved verbatim at: <路径>`；agent 可直接 `read_file` 读原文件，不再凭文件名全盘 find。提取文本仍前置注入，原文件路径是有损提取的兜底。
  - `read_file` 接通表格/演示文稿族（xlsx/xls/ods/ppt/pptx/odp）：走 doc-extract 引擎链（exceljs 等）输出表格文本，此前会把 zip 容器当纯文本读成乱码。
  - 纯附件无文字发送时，气泡占位文案按附件构成显示「(图片)/(文档)/(压缩包)/(附件)」，不再一律「(图片)」。
- **图片格式全链归一（修复会话毒化）**：
  - 图片进模型历史一律按字节 magic 归一：bmp 自动转 PNG（模型仍可见）、声明与字节不符以字节为准修正、tiff/坏图定点换占位文本。
  - 上线前兜底闸：每个请求发出前定点清除不识格式，首轮即生效——DeepSeek「unsupported image」整请求 400 绝迹；剥图经通知告知，不再静默。
- **TUI classic 全高视口（收编 PR #528，感谢 @yq04）**：
  - 指令摘要（› 执行中/上一轮）钉在终端窗口顶部；窗口高度/宽度变化后从 (1,1) 重锚整帧，输入区保持贴底；修复 caret 消失被「内容未变化」短路吞掉的光标滞留。
  - /clear 与会话切换只清显示边界、不动 pager 历史；退出时恢复 shell 底行光标；读屏模式保留紧凑输出。
- **生态与修复**：
  - ChatGPT 桥新增 Tianshu MCP server（MCP 客户端可直接挂接天枢能力）。
  - 公开仓 README 重新设计收编（PR #527）与死链兜底（同步白名单补齐 + 守卫测试）。
  - worker 续跑与测试门禁修复；快照 worktree 继承 ripgrep 工具路径。

## 已知限制

- 表格预览为「预览定位」：超 500 行 × 50 列截断，合并单元格/样式/图表不还原；完整内容请用系统应用打开。
- TUI 全高视口已经模拟终端全量回归（3473 项），真实 Windows Terminal / ConHost 的缩放视觉验收建议发版后实地确认。
