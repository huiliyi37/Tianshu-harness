# v3.32.0 — 工作过程自动收起 · 桌面交互与执行连续性修复

> 日期：2026-10-15
> 上一版本：v3.31.0

## 会话阅读

- 标准模式将连续说明、推理及工具活动归入同一工作区间。运行中显示最近进度，结束后按现有“自动收起工作过程”设置收为一行摘要，可展开完整记录。
- 最终交付独立展示。环境验证触发续轮时，原交付、后续验证过程和追加交付保持边界，避免正文被一并折叠。
- 保留详细模式、手动展开与固定状态；阅读上文、选择文本或焦点停留在过程内容时，延迟自动归组与收起，减少阅读位置跳动。

## 桌面交互

- 输入框保留紧凑的两行起始高度，随内容增长至视口限制后仅纵向滚动。修复非默认主题下的横向滚动条及矮窗口中的高度判断，保持底部工具栏可用。
- 右侧工作面首次展开显示功能菜单，之后按当前会话或项目恢复上次功能。菜单和文件工作面互斥展示，避免固定文件树穿透；保留目录展开、预览与滚动状态。现有快捷键不变：⌘B 控制左栏，⌘⇧B 控制右栏。
- 图片按原图及变体归并后计算附件槽位，修复设置上限为 4 张却只能加入 3 张的问题。
- 消息操作使用更明确的图标和提示；会话总览中的审查发现可通过已读状态清除“需要处理”标记。
- 修复下拉菜单长文案裁切、会话标签滚动条悬停抖动及 Insights 窄内容区布局。

## 更新、账户与用量

- 更新下载避开已知缓慢路由，继续执行通道策略、摘要和签名校验。
- 统一账户身份与设备额度准入，减少不同入口的身份及额度判断差异。
- 用量同步增加精确小时维度；继续沿用现有本地记录和用户显式配置的同步方式。

## 运行时与构建

- 修复 worker 恢复首请求因注入差异导致的缓存前缀拒发；在受控边界开启新缓存代次，隔离重试前缀并持久保存恢复回退。
- 收编社区 #476 的受保护路径符号链接竞态修复、#477 的 VS Code 模型凭据过滤及 npm bin 运行时发现改进、#478 的重试与恢复缓存修复。
- Linux 容器构建检查镜像实际平台及架构，固定使用校验后的镜像 ID；apt 独立处理代理，并修复 macOS 扩展属性影响容器拷贝的问题。
