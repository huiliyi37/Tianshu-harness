## 11. Linux 桌面端双架构（本版平台说明）

- **平台覆盖**：`Tianshu_3.26.0_amd64.AppImage`（x86_64）与 `Tianshu_3.26.0_aarch64.AppImage`（ARM64）双包随本版发布；arm64 覆盖树莓派 64 位、ARM Linux 笔记本等设备
- **运行要求**：glibc ≥ 2.35（Ubuntu 22.04+ / Debian 12+ 等主流发行版）；免安装，`chmod +x` 后直接运行；推荐 X11 会话（Wayland 未验证）
- **构建方式**：本版起 Linux 双架构改由**本地 OrbStack 容器**构建（`scripts/build-linux-container.sh`，arm64 原生 + amd64 Rosetta）——私有仓 GitHub Actions 分钟额度不稳定，本地容器零账单；pango 剔除重打包（issue #80 修复）沿用既有脚本
- **已知限制**：语音输入暂不可用（whisper 社区构建缺位，自动降级浏览器语音）；桌面自动更新对 Linux 同样生效
