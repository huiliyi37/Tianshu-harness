# v3.32.1 — v3.32.0 重发（发布工程修正）

> 日期：2026-10-15
> 上一版本：v3.31.0（稳定通道）；v3.32.0 未进入稳定通道

## 本版说明

**v3.32.1 与 v3.32.0 的产品内容完全一致**，包含「工作过程自动收起、桌面交互与执行连续性修复」全部内容——见 [v3.32.0 完整说明](v3.32.0.md)。

v3.32.0 在受控灰度阶段因发布工程错误被撤销（revoke），未进入稳定通道：候选 catalog 包含了五个平台，而灰度只 stage 了三个实测平台，二者不齐导致晋升门永远不可达。该版本已在更新控制面留痕撤销，已安装 3.32.0 的用户不受影响，将直接收到 3.32.1 更新。

本版修正发布流程本身：候选清单只纳入通过真机验收的平台（darwin-aarch64、windows-x86_64、linux-x86_64），darwin-x86_64 与 linux-aarch64 的安装包仍随 Release 页提供手动下载，但不参与本次自动更新灰度。

## 内容清单

与 v3.32.0 相同：

- **会话阅读**：工作过程按区间自动收起；交付正文、环境验证续轮和追加交付分别保留边界。
- **桌面交互**：修复输入框横向滚动条、右栏文件树叠层、第 4 张图片无法加入；消息操作提示与会话总览已读状态改进。
- **更新、账户与用量**：更新下载避开已知缓慢路由；账户身份与设备额度准入统一；小时级精确用量同步。
- **运行时与构建**：worker 恢复与重试缓存前缀修复；收编社区 #476/#477/#478；Linux 容器构建平台校验加固。

## 升级注意

- 从 3.31.0 升级：内容与 v3.32.0 说明一致，无需迁移。
- 已装 3.32.0 的用户：直接自动更新到 3.32.1 即可，无额外操作。
