# v3.32.1 — Reissue of v3.32.0 (release-engineering fix)

> Date: 2026-10-15
> Previous: v3.31.0 (stable channel); v3.32.0 never reached the stable channel

## About this release

**v3.32.1 ships exactly the same product content as v3.32.0** — collapsible work intervals, desktop interaction fixes and execution-continuity repairs. See the [full v3.32.0 notes](../releases/v3.32.0.md) (Chinese) for details.

v3.32.0 was revoked during the controlled rollout and never entered the stable channel: the candidate catalog covered five platforms while only three verified platforms were staged, and that mismatch made promotion permanently unreachable. The revocation is recorded in the update-control history. Users who already installed 3.32.0 are unaffected and will simply receive 3.32.1 as the next update.

This release also corrects the release process itself: the candidate manifest now only includes platforms with real install acceptance (darwin-aarch64, windows-x86_64, linux-x86_64). darwin-x86_64 and linux-aarch64 installers remain on the Release page for manual download but do not participate in this rollout.

## Content

Same as v3.32.0:

- **Conversation reading**: work collapses by interval; deliveries, runtime verification follow-ups and additional deliveries keep separate boundaries.
- **Desktop interactions**: fixes for the composer horizontal scrollbar, right-panel file-tree overlap and the missing fourth image slot; clearer message actions and overview read state.
- **Updates, account & usage**: update downloads avoid known slow routes; unified account identity and device quota admission; precise hourly usage sync.
- **Runtime & build**: worker resume and retry cache-prefix fixes; community PRs #476/#477/#478; hardened Linux container build platform checks.
