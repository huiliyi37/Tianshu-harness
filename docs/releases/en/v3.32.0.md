# v3.32.0 — Collapsible Work Intervals and Desktop Reliability

> Date: 2026-10-15
> Previous: v3.31.0

## Conversation reading

- Standard mode groups consecutive narration, reasoning and tool activity into a work interval. It shows recent progress while running and collapses completed work to a summary using the existing auto-collapse setting. Full records remain expandable.
- Final deliveries remain separate. When runtime verification triggers another turn, the original delivery, verification work and additional delivery keep their own boundaries.
- Detailed mode, manual expansion and pinned state remain available. Automatic regrouping and collapse wait while the reader is viewing, selecting or focusing process content, reducing position jumps.

## Desktop interactions

- The composer starts at a compact two-line height and grows to the viewport limit before scrolling vertically. Fixes horizontal scrollbars in non-default themes and incorrect height limits in short windows while keeping the toolbar accessible.
- The right panel shows its launcher on first use, then restores the last workspace for the current session or project. The launcher and file workspace are mutually exclusive, preventing pinned file trees from overlapping. Directory expansion, previews and scroll state are preserved. Existing shortcuts remain: ⌘B for the left sidebar and ⌘⇧B for the right panel.
- Attachment slots are counted after grouping original images and variants, fixing cases where only three images could be added with a four-image limit.
- Message actions have clearer icons and hints. Reading review findings can clear their attention marker in the session overview.
- Fixes clipped dropdown labels, session-tab scrollbar movement on hover and Insights layouts in narrow content areas.

## Updates, accounts and usage

- Update downloads avoid known slow routes while retaining channel policy, digest and signature checks.
- Account identity and device-quota admission use consistent rules across entry points.
- Usage synchronization adds precise hourly reporting while retaining local recording and explicitly configured synchronization.

## Runtime and builds

- Worker resume can start a new cache generation at a controlled boundary when first-request injections differ, instead of rejecting the continuation. Retry prefixes are isolated and recovery fallback is persisted.
- Adopts community fixes from #476 for protected-path symlink races, #477 for VS Code model-credential filtering and npm-bin runtime discovery, and #478 for retry and resume caching.
- Linux container builds verify the image's actual platform and architecture and run the checked image ID. apt handles proxies independently, and container copying avoids macOS extended-attribute failures.

## Upgrade and release status

Existing sessions, themes and collapse settings require no migration. The runtime and desktop share version 3.32.0; the VS Code extension retains its independent version cycle.

These notes accompany source preparation. Updates become available only after platform packages, signatures and real upgrade acceptance complete the controlled release process. Source builds and browser regressions do not certify packaged upgrades.
