## 分层设计 · Layering

- **Layer 0 — `CLAUDE.md` / `AGENTS.md`**: 稳定工程操作手册（短小、可执行、前缀缓存友好 / short, actionable, cache-friendly）。
- **Layer 1 — Star Charter (`src/agent/star-domain.ts`)**: 运行时星域定义与压缩方法论（挥发段按域装配 / runtime cognitive stance definitions）。
- **Layer 2 — Star Archive (`docs/stars/`)**: 本目录下的完整星辰碑文与分卷档案（full stele & per-star records）。
- **Layer 3 — Historical Snapshots**: 早期完整提示词快照（如 `CLAUDE.tianshu-2.0.md` 归档与 [`immune-mistake-redesign.md`](./immune-mistake-redesign.md) 专项记录）。
