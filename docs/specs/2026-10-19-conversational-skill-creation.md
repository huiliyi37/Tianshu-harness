# 对话式技能创建（公开内核部分）

关联 [#459](https://github.com/huiliyi37/Tianshu-harness/issues/459)。用户描述目标，由 AI 引导生成可审核的技能草稿；无需用户预先理解 YAML。桌面入口由闭源仓接入，本变更不能单独关闭该 issue。

## 功能需求与验收

| 编号 | 可观察行为 | 验收场景 |
| --- | --- | --- |
| FR-001 | 内置创建技能支持自然语言发现和显式调用，完整指令按需加载 | 中文/英文创建请求能发现技能；显式调用保留用户任务；发现列表不包含正文 |
| FR-002 | 指令先确认目标、触发场景、输入输出、边界与个人/项目范围，再生成草稿 | 已提供的信息不重复询问；description 描述何时使用；产出包含步骤、示例、验收和限制；不虚构已验证 |
| FR-003 | 提供无需再次调用模型的草稿保存命令，复用现有审核存储 | 合法 Markdown 保存到所选范围的草稿区；未指定范围、无文件、非法 YAML、空描述或空正文均失败且不产生草稿 |
| FR-004 | 保存草稿不发布技能，不改变当前会话固定版本 | 草稿在列表可审核，但技能目录与新会话发现均不可调用；显式批准后仅新会话可用；拒绝不安装 |
| FR-005 | 桌面接入复用既有技能调用与草稿接口 | 通过现有 HTTP 保存的草稿可由 CLI 审核，反之亦然；桌面按钮、窗口跳转与预填不在公开仓实现 |

## 范围

本期只创建单文件技能草稿。已有技能修改、评测框架、资源包生成、桌面按钮与窗口实现均不在本期。复用现有草稿编辑和重名批准规则，不增加存储格式、状态、后台任务或自动发布。
